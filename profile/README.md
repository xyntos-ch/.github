# Xyntos GmbH

**Embedded software engineering from Switzerland** 🇨🇭

We design and build reliable embedded software — with a focus on CAN/CANopen communication, clean object-oriented C++, and ARM Cortex-M microcontrollers, from bare-metal to FreeRTOS.

## 🔧 What we do

- CANopen device and master development
- Embedded software architecture and firmware development in modern C++
- STM32 / ARM Cortex-M, bare-metal and FreeRTOS
- Unit-tested, CI-driven embedded development

## 🚀 CANoopEn
